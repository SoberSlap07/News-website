# News-website
I developed this **News Website** using **HTML**, **CSS**, and **JavaScript**. It’s a fully responsive, dynamic news platform that fetches and displays the latest headlines using a news API. The goal of this project was to enhance my front-end development skills and build a functional, user-friendly interface without relying on any external frameworks or libraries.

## 🔍 Features
- 📰 Real-time news updates fetched from a public news API
- 🔎 Search functionality for user-defined topics
- 🗂️ Categorized news sections (e.g., Business, Sports, Technology)
- 📱 Responsive design for mobile, tablet, and desktop
- 🎨 Clean and modern UI with custom styling
- ⚡ Fast performance with JavaScript

## 🛠️ Technologies Used
- **HTML5** – Structuring content
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6)** – Dynamic data fetching and DOM manipulation
- **News API** – For fetching live news data
